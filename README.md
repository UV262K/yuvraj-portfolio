# Yuvraj — Portfolio Website

Personal portfolio site for cloud and full-stack development.

## Preview locally
Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment
The repository includes an AWS Amplify build configuration (`amplify.yml`). Connect this repository to AWS Amplify Hosting to deploy and enable automatic updates on pushes.

## Note
The HTML references `css/style.css` and `js/main.js`. Add those supporting files, plus any required assets, to complete the site styling and interactive behavior. Update the placeholder email and profile links in `index.html` before publishing.
