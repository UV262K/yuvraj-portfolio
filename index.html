⚙03 · How I work

Improve the process, not just the output

  • Start with the problem: identify the user, friction point and desired outcome.
  • Build in small steps: separate responsibilities and keep changes easier to review.
  • Check the result: compare against a baseline and test the same scenario before making an efficiency claim.
  • Keep it usable: prioritise responsive layouts, readable feedback and clear next actions.
